# Roadmap

本文档维护 PanePilot 的阶段目标和交付节奏。

## 里程碑

| 阶段 | 目标 | 交付物 | 状态 |
|---|---|---|---|
| v0.1 | 建立可运行的 Spectacle-like 核心体验 | 菜单栏 App、快捷键、窗口布局、撤销/重做、本地打包、GitHub Release | 已完成 |
| v0.1.1 | 提供正式签名分发包 | Developer ID signed、notarized、stapled DMG 和 GitHub Release | 已完成 |
| v0.2 | 提升可配置性 | 快捷键偏好设置、禁用动作、菜单状态优化 | 未开始 |
| v0.3 | 提升窗口适配质量 | 终端类 App 尺寸约束、更多窗口状态检测、多显示器边界优化 | 未开始 |
| v0.4 | 正式分发准备 | Developer ID 签名、公证、更新说明、下载页 | 未开始 |

## 当前优先级

1. 保持核心布局逻辑可测试。
2. 后续再做偏好设置。
3. 为正式发布补充真实桌面验收证据。
