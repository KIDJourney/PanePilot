# Glossary

| 术语 | 定义 |
|---|---|
| Agent 入口 | agent 新会话首先读取的项目说明文件，当前为 `AGENTS.md` |
| 长期知识库 | 可跨会话复用、进入版本控制的项目事实，当前为 `docs/` |
| 产品文档 | 描述用户、问题、范围、需求和非目标的文档 |
| 技术文档 | 描述架构、模块、接口、数据、依赖和运行方式的文档 |
| 测试方案 | 描述验证目标、覆盖范围、命令、验收标准和风险的文档 |
| 交接记录 | 本轮工作结束时留给下一轮 agent 的状态摘要 |
| 决策记录 | 说明背景、选择、理由和影响的长期记录 |
